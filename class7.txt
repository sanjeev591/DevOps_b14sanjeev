Types of link:

1. Hard link
2. Soft link

Hard link:

Hard link is an additional name for an existing file where both the original file and
the hard link will share the same inode which means they are same files with diff name.

Inode (index node): It is a data structure that stores information about files/dir's size,owner..etc

How to create hardlink?

Synatx: ln <file-name> <link-name>

Note:

1. When we make any change to original file,we can see those changes in the link.
2. If you rename the original file, the link will still work
3. If we delete the original file then also a link created from orinal file will work

Soft link:

soft link is a pointer to a file. It does not share same inode as the original file


How to create softlink?

Synatx: ln -s <file-name> <link-name>

Note:

1. When we make any change to original file,we can see those changes in the link.
2. If you rename the original file, the link will not work
3. If we delete the original file then link will not work
